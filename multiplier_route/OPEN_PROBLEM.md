# OPEN PROBLEM: 全空间 M_{49,1/25} < 4 的严格证明

> 状态: 开放问题（社区交接版）。2026-09-01。
> 项目已交付的层级与缺口见下；本文件给出最小、明确、可验证的开放问题。

## 1. 精确目标

令 k=49, ε=1/25, R_k = {t ∈ [0,∞)^k : Σt ≤ 1}，(1±ε)R_k 为缩放单纯形。对支撑在
(1+ε)R_k 上的平方可积 F ≢ 0 定义（Polymath8b, Theorem 3.12）：

  I(F) := ∫_{(1+ε)R_k} F² dt,
  J_{i,1−ε}(F) := ∫_{(1−ε)R_{k−1}} (∫₀^∞ F dtᵢ)² dt_{≠i},
  M_{k,ε} := sup_F [Σ_{i=1}^k J_{i,1−ε}(F)] / I(F).

**开放问题: 证明 M_{49,1/25} < 4。**
（意义: 若成立且结合 Bombieri–Vinogradov, 该配置不能认证 DHL[49,2],
即不能由直径 240 的可容许 49 元组改进 246——注意这是边界确认的定理化, 与孪生素数猜想本体无关。）

## 2. 已知的三个层级

### A 级: V_D 上的区间正定证书（已交付, 严格）

对嵌套多项式空间 V_D = span{(1+ε−Σt)^r·p_γ : r+deg γ ≤ D, γ parts≥2}，
广义特征问题 (J_D, I_D) 的最大特征值的 k 倍 M(D) = k·λ(D) 满足 M(D) ≤ M_{k,ε}（min-max, 严格）。

- 区间算术证书（iv_strict3 管线, 可复验）: k=49 parts≥2 D=19, k=48 parts≥2 D=19,
  偶数基 D=29 —— 全部主元 > 0, STRICT M(D) < 4。
- 高精度值（mpfr 256–512 bit, 有效精确）: M(19)=3.9652210893, M(21)=3.974689,
  …, M(33)=3.9902624483（偶数基）。
- 结合发表上界（Prop 6.5/Remark 6.6, 文献审计见 §4）: **M_{49,1/25} ∈ [3.9903, 4.1318]（严格包络）**。

### B 级: 嵌套 Ritz 值与数值外推（已交付, 经验性）

- 9 个嵌套子空间值单调递增, 增量比值稳定 ~0.55–0.60 且单调递减。
- 三种独立外推（几何尾和 ~3.9911; δ-残差修正 ~3.9935; Aitken/Shanks ~3.9923–3.9933）
  一致指向 ≈3.9936, 保守区间 [3.992, 3.995]。
- k=50 校准与论文发布值一致（框架自洽）。
- **等级: B。外推假设"增量按几何衰减延续"是经验假设, 不是定理。**
  这些数据不能替代 §3 的引理——有限维下界再高也不排除全空间越过 4 的可能（严格上界 4.1318 > 4）。

### C 级: 有限维到全空间的缺口（未解决, 本开放问题核心）

**缺失一个显式尾项界或直接不等式**, 例如以下二选一:

1. **算子尾项界**: 存在可计算的 D₀ 与显式函数 c(D)（可验证, 趋于 0）使得
   M_{k,ε} ≤ M(D) + c(D) 对一切 D ≥ D₀ 成立, 且 M(D₀) + c(D₀) < 4。
2. **全空间正权**: 构造 w: (1+ε)R_k → (0,∞)（不要求光滑; 允许分段/其他类）使逐点
   不等式 Σ_{i∈A(t)} W_i(t_{≠i}) ≤ λ*·w(t) 对某 λ* < 4 成立（W_i = ∫w dtᵢ, A(t) 为活跃集）。
   这是乘子引理（multiplier_lemma.md, 已完整证明）的充分条件。

## 3. 为什么现有数据不能替代该引理

- A 级给出 M 的下界: 再逼近也只能得到 M ≥ 3.9903, 无法排除 M ≥ 4。
- B 级外推是假设性的: 没有任何定理保证 M(33) 之后增量的衰减延续; 反例模式（增量骤增）
  在原则上不被数据排除（虽然与全部观测矛盾）。
- 标准上界工具在试验中失败（均已被记录为对**已测试构造**的失败, 非普遍不可能）:
  - 乘子/CS 权族: 已测试的光滑逐 i 族数值地板 ≈4.13–4.14; 采样 LP 因基病态 (cond~1e49)
    退化。**没有**对任意权类的下界证明（因此"地板"是经验观察）。
  - 残差型谱上界 (Kato–Temple): 试验函数 u₁₉ 的完整残差 δ_rel = 0.106 大于谱隙
    ρ−μ₂ ≤ 0.0705（KATO_AUDIT.md）——该标准构造不可行; **没有**对任意试验函数的失败证明。
- 结构性观察（特征函数在超平面 Σ_{j≠i}t_j = 1−ε 处有 O(0.1) 跳跃, k=2 闭式解支持）提示
  光滑构造的天然障碍, 但跳跃本身是观察/论证, 不是定理。

   （或更大的 D）。资产: 精确矩阵构造 (frac_multi_all.py), V_D 基与全部数值。
