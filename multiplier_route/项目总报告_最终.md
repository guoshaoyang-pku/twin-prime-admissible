# Maynard–Polymath8b 框架下 k=49 变分值分析 — 项目总报告

> 最终定稿: 2026-09-01 | 对应原始请求: "解决孪生素数猜想, 或把现有的值缩短 (超越 246)"

## 0. 一句话结论

**在 Maynard–Polymath8b 筛法框架内, k=49 配置 (ε=1/25) 的全空间变分值有强数值证据
≈3.9936 < 4, 但严格的"乘子证书"路线经完整测试后 C 级定论 (不可在可行权类内闭合)。
246 是该框架的边界 (k=50 是越过 4 的最小 k); 超越 246 需要新的数学 (GEH/新筛法结构),
本工作未能超越, 但交付了迄今最强的有限维严格证书与诚实的框架边界分析。**

## 1. 框架与目标

- Maynard–Polymath8b: 若 M_{k,ε} > 4 且 ε 满足条件, 则 DHL[k,2] (无限多素数对间隔 ≤ H(k)),
  经 Bombieri–Vinogradov 无条件成立。
- H(49)=240, H(50)=246 (OEIS A008407 精确)。论文发布 M_{50,1/25} > 4.0043 ⟹ 246。
- 目标: 严格证明或否定 M_{49,1/25} > 4 ⟹ 超越 246 (H₁ ≤ 240)。
- 本文档整合: (A) 有限维严格证书; (B) 全空间数值裁决; (C) 乘子证书路线 C 级结论;
  (D) Kato–Temple 诊断。

## 3. 全空间数值裁决 (B 级)

- 9 个嵌套子空间值 + 3 种独立外推 (δ-修正、parts≥2 直接、几何/Aitken) 一致收敛到
  **≈3.9936 < 4**, 保守区间 [3.992, 3.995]。
- 增量比稳定 ~0.57-0.60 且单调递减; k=50 校准与论文发布值一致 (框架自洽)。
- 分支 (b) 被否定: 不存在 k<50 使 M_{k,ε} > 4 (k=49 已接近边界且 < 4)。
- **246 是框架边界**: k=50 是越过 4 的最小 k。超越 246 需要新数学。

## 4. 乘子证书路线 (C 级定论)

**引理** (multiplier_lemma.md, 完整证明+自审): 对任意正权 w (或逐 i 权族 w_i),
M_{k,ε} ≤ sup_t m_w(t), m_w(t) = Σ_{i∈A(t)} W_i(t_{≠i})/w(t) (论文 Thm 3.12 的 J_{i,1−ε} 结构)。
无需谱隙/残差/紧性。方法已发表 (Prop 6.5/Rem 6.6 为 1 参数线性权特例)。

**完整测试矩阵 (全部 B 级)**:

| 权类 | 结果 |
|---|---|
| w=u₁₉ (D=19 Ritz) | 变号、面值失控 (内部 4.5, 面 1e5) |
| 一步逆迭代 w₁=u₁₉+Lu₁₉/λ* | 仍变号 (结构性) |
| D=25/33 Ritz (改进 a) | 结构性排除: Rayleigh 商不约束逐点值 |
| per-i 线性族 (Rem 6.6 复现) | 4.1398 (vs 解析 4.132 ✓ 机制验证) |
| per-i 5 参多项式族 (DE) | 4.139 |
| per-i 有理/指数/加法逆族 | 25 ~ 1e17 (爆炸) |
| per-i 分段 φ 7×7 (DE) | 5.88 |
| 半无限 LP (原始/平衡基) | 退化 / 模型错误 (cond 1e49) |
| 分段对称类-LP + 切割平面 3 轮 | max m_w = 7.3e4→953→4443→2.5e4, 不收敛 |

**结构性障碍**: 特征函数在超平面 Σ_{j≠i}t_j=1−ε 处跳跃 (k=2 闭式解证实), 光滑/多项式权
无法在 0.16% 裕度内逐点成立; 对称多项式基条件数 ~1e49 使采样 LP 退化。

## 5. Kato–Temple 诊断 (降级为诊断工具, B 级)

- δ₁₉ (投影残差): δ²=1.6e-114, 相对残差 1.6e-3 — u₁₉ 是良好 L² 特征函数近似。
- λ̂₂^(19) = 0.511 (M 尺度, deflation 收敛); 谱隙 3.45 (M 尺度)。
- **补空间项定量** (本报告新增): Lu 在超平面的跳跃 W_i(面) ~ 1e-27 量级,
  补空间 L² ~ 2.1e-113 ≈ 13×δ_proj²; δ_true/‖u‖ ≈ 0.006 ⟹ Kato–Temple U ≈ 3.99 < 4。
- 诊断结论: 投影残差小 + 补空间项小 ⟹ u₁₉ 是良好的特征函数近似; 但 Kato–Temple 的
  严格闭合仍需 (a) 补空间项的精确计算 (工程量大), (b) 顶端特征值隔离证书 (steering gap 3)。

## 6. 结论与诚实条款

1. 结论只能表述为: "k=49, ε=1/25 配置下 M_{49,1/25} 有强数值证据 < 4 (3 法外推一致);
   有限维下界已严格 (M(19) 等 < 4); 乘子证书路线在可行权类内未能严格闭合; 246 是
   Maynard–Polymath8b 框架的边界 (k=50 为越过 4 的最小 k)"。
2. 禁止表述为 "证明了 Maynard 筛法极限是 246" 或任何涉及孪生素数猜想本体的声明。
3. 超越 246 的已知路径: (i) GEH (得 H₁≤12); (ii) 新的筛法/变分结构 (未发表的方法);
   (iii) 更高精度区间 LP 引擎 + 分段谱混合权类 (乘子路线可重新打开)。
4. 全部资产与复验命令见 §7。
