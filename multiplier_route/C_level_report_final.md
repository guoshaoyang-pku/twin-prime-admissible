# C 级报告（草案）— 乘子路线在可行权类内未闭合

> 状态: **定稿** (2026-09-01)。切割平面 3 轮后最终验证 max m_w = 25199 (6848/20000 违例)。
> 结论: 乘子路线在已测试的可行权类内**不可闭合**。项目定格为有限维证书 + 数值证据。

## 1. 目标与机制（回顾）

M_{49,1/25} < 4 的乘子证书: 找严格正权 w (或逐 i 权族 w_i) 使逐点不等式
Σ_{i∈A(t)} W_i(t_{≠i}) ≤ λ*·w(t), λ* < 4 成立 (论文 Thm 3.12 的 J_{i,1−ε} 结构)。
该引理已完整证明并自审 (multiplier_lemma.md)。方法本身已发表 (Prop 6.5/Rem 6.6, 特殊线性权),
k=49, ε=1/25 的 <4 上界在文献中不存在 (S1 完成)。

## 2. S2 探针结论（已完成, B 级）

- w = u₁₉ (D=19 parts≥2 Ritz): 在单纯形内部**变号** (S=0.2 处 w=−3.7e-12), 边界面值失控 (~1e-26)
  ⟹ sup m_w: 内部 4.51, 边界面 ~1e5。**不可用**。
- δ₁₉ 诊断: 相对残差 1.6e-3 — u₁₉ 是良好 L² 特征函数近似 (0.16%), 但乘子证书需要**逐点**控制。
- 根因 (结构性): 特征函数在超平面 Σ_{j≠i}t_j=1−ε 处**跳跃** (k=2 闭式解证实 breakpoints;
  跳跃 = ∫₀^{2ε}ψ > 0), 多项式 Ritz 向量的逐点值不受 Rayleigh 商约束 (L² 好 ≠ 逐点好)。

## 3. S3 决策门: 所有可行权类的尝试与失败模式

| 权类 | 结果 | 失败模式 |
|---|---|---|
| w = u₁₉ (Ritz) | sup ≫ 4.01 | 变号+面值失控 |
| 一步逆迭代 w₁ = u₁₉+Lu₁₉/λ* | 仍变号 | 同上 (结构性) |
| D=25/33 Ritz (改进 a) | 未测试全, 结构性排除 | 点值不受控与 D 无关 |
| per-i 线性族 (Rem 6.6) | 4.1398 | 复现文献界 |
| per-i 5 参多项式族 | 4.139 | DE 优化无改进 |
| per-i 有理/指数/加法逆族 | 25–1e17 | 爆炸 |
| per-i 分段 φ (7×7 网格) | 5.88 | DE 后更差 |
| 半无限 LP: 原始基 | 退化解 ‖c‖₁=1.5e15 | 条件数 1e49 |
| 半无限 LP: 平衡基 | HiGHS 模型错误 | 条目 1e47 |
| 分段对称类-LP (次数 5) | 退化解 (锚点尖峰) | 采样 LP 的固有漏洞 |
| 切割平面类-LP (次数 5, 3 轮) | max m_w = 7.3e4→953→4443→**2.5e4** (最终 20k 点验证) | 不收敛: 每次重解出现新爆炸区, ‖c‖₁ 增长 6.8→200→2879 |

**结构性障碍总结**:
1. 特征函数分段 (超平面跳跃) ⟹ 光滑/多项式权无法在 0.16% 裕度内逐点成立 (跳跃填充代价 ~1%)。
2. 分段权类需连续统约束, 但对称多项式基条件数 ~1e49 (float64 下逐点评估与 LP 均不可靠),
   采样 LP 存在"锚点尖峰"漏洞 (函数可在采样点间不受控)。
3. 逐 i 族 (唯一能约化到低维可验证结构的形式) 的地板 ≈4.13, 更灵活的族全部更差。

## 4. 项目定格（若 C 级）

**已交付 (A 级, 区间证书)**:
