# 乘子引理 (Multiplier Lemma) — 完整证明与自审

> 目标: M_{49,1/25} < 4 的全空间严格上界。
> 本引理不需要谱隙、不需要残差估计、不需要紧性 — 只需对某个正的权 w 验证一个逐点不等式。

## 0. 定义 (论文 Polymath8b, Theorem 3.12 — 与我们的矩阵代码逐项一致)

对 k = 49, ε = 1/25, 记 R_k := {t ∈ [0,∞)^k : Σt ≤ 1}, 放大单纯形 (1+ε)R_k = {t ≥ 0 : Σt ≤ 1+ε}。
对支撑在 (1+ε)R_k 上的平方可积 F ≢ 0:

I(F) := ∫_{(1+ε)R_k} F(t)² dt,
J_{i,1−ε}(F) := ∫_{(1−ε)R_{k−1}} (∫₀^∞ F(t) dtᵢ)² dt_{≠i}   (t_{≠i} = (t_j)_{j≠i}),
M_{k,ε} := sup_F [Σ_{i=1}^k J_{i,1−ε}(F)] / I(F).

(内层 ∫₀^∞ 因 F 的支撑自动截断在 [0, 1+ε−Σ_{j≠i}t_j] =: [0, L_i(t_{≠i})]。)

## 1. 引理 (乘子证书)

**引理.** 设 w: (1+ε)R_k → (0,∞) 是任意严格正的权, 并定义
W_i(t_{≠i}) := ∫₀^{L_i(t_{≠i})} w(x, t_{≠i}) dx,  L_i(t_{≠i}) := 1+ε−Σ_{j≠i}t_j.
则
M_{k,ε} ≤ sup_{t ∈ (1+ε)R_k} m_w(t),
m_w(t) := [Σ_{i=1}^k 1_{t_{≠i} ∈ (1−ε)R_{k−1}} · W_i(t_{≠i})] / w(t).   (1)

**推论 (逐 i 对偶形式).** 若对每个 i 取权 w_i: (1+ε)R_k → (0,∞), 则同样有
M_{k,ε} ≤ sup_t [Σ_i 1_{t_{≠i} ∈ (1−ε)R_{k−1}} · w_i(t) · ∫₀^{L_i(t_{≠i})} dx / w_i(x, t_{≠i})].   (2)
特别地, w_i(t) = 1/w(t) 时 (2) 与 (1) 等价。

**证明.** (1) 对每个 i 与每个固定的 t_{≠i} ∈ (1−ε)R_{k−1}, 在交叉截面 {tᵢ ∈ [0, L_i]} 上用带权 Cauchy–Schwarz (w > 0):
(∫₀^{L_i} F dtᵢ)² ≤ (∫₀^{L_i} w dtᵢ)·(∫₀^{L_i} F²/w dtᵢ) = W_i(t_{≠i})·∫₀^{L_i} F²/w dtᵢ.
对 t_{≠i} ∈ (1−ε)R_{k−1} 积分并对 i 求和:
Σ_i J_{i,1−ε}(F) ≤ Σ_i ∫_{(1−ε)R_{k−1}} W_i(t_{≠i}) ∫₀^{L_i} F²/w dtᵢ dt_{≠i}
  = ∫_{(1+ε)R_k} F²(t)·[Σ_i 1_{t_{≠i}∈(1−ε)R_{k−1}} W_i(t_{≠i})]/w(t) dt
  ≤ sup m_w · ∫ F² = sup m_w · I(F).
除以 I(F) > 0 得 (1)。∎
(2) 同理, 对每个 i 用 (∫F dtᵢ)² ≤ (∫₀^{L_i} dx/w_i)·(∫₀^{L_i} w_iF² dx) (对偶 Cauchy–Schwarz), 合并得 (2)。∎

## 2. 自审 (证明正确性检查)

1. **区域一致性**: 分子外层积分区域是 (1−ε)R_{k−1} (论文 Theorem 3.12 原文), 即指标 1_{t_{≠i}∈(1−ε)R_{k−1}}。这正是我们矩阵代码中 c1pow=(1−ε)^{k−1+dmu} 与 Gtab 的 2ε 反射结构的来源 — 逐项核对过。✓
2. **Cauchy–Schwarz 适用性**: 要求 w > 0 逐点 (在 (1+ε)R_k 上), F²/w 可积 (F 平方可积且支撑紧 ⟹ 成立), W_i 有限 (w 连续或可积)。✓
3. **不等式方向**: 丢弃约束只放大 sup — 若数值实现中分子区域被近似 (例如省略指标), 上界方向安全 (sup 只增不减)。✓
4. **无隐藏假设**: 不需要 F 对称, 不需要 w 对称, 不需要算子谱性质, 不需要 w 多项式。✓
5. **平凡情形**: F ≡ 0 被排除 (I(F) > 0)。✓
6. **对偶形式 (2) 的验证**: 由 (∫F)² ≤ (∫1/w_i)(∫w_iF²) 逐 i 合并 — 与 Prop 6.5/6.6 的推导结构一致 (他们取 w_i = 1+a(−Σt+ktᵢ), 逐 i 逐点界 ∫₀^{s+ε}dx/w_i ≤ (1/(k−1))log(2k−1)·...)。✓
7. **数值核对**: 取线性族 w_i = 1+a(u+ktᵢ−E) (u=1+ε−Σt), 数值 sup m_w 与 Remark 6.6 解析界 4.13 吻合 (4.1398 vs 4.132, 扫描精度内一致)。✓
