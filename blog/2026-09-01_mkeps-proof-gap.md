# 关于 Polymath8b 论文 Mkeps 上界证明的一个缺口（附核验）

> **日期**: 2026-09-01
> **涉及**: D.H.J. Polymath, *New equidistribution estimates of Zhang type*,
> arXiv:1407.4897 — **Proposition 6.5** 与 **Remark 6.6**
> **性质**: 辅助命题的**证明缺口**（proof gap）；不涉及结论证伪；主结果 H₁ ≤ 246 **不受影响**
> **核验**: 独立脚本 `verify_mkeps_gap.py`（精确有理数 + mpmath 50dps，5 项全部通过）

## TL;DR

arXiv:1407.4897 的 Proposition 6.5 声称对一切 k ≥ 2, 0 ≤ ε < 1 有
M_{k,ε} ≤ (k/(k−1))·log(2k−1)。其证明的最后一步（"summing in i"）需要
Σ_{有效切片} (1−Σt+kt_i) ≤ k 对 (1+ε)R_k 上几乎处处 t 成立。我们构造了
**正测度开集**上的反例：当 t 有 13 个坐标 ≈ 2ε（k=49, ε=1/25）时该量为
**50.4 > k = 49**。Remark 6.6 的 a 参数化在 **a > 1/(1+ε)** 时同样受此缺口
影响；**a ≤ 1/(1+ε) 时严格成立**，其端点给出
M_{k,ε} ≤ (1+ε)·k/(k−1)·log k —— 这是该权族的最优严格上界。

**影响范围（重要）**：论文的主定理（H₁ ≤ 246）**不依赖** Prop 6.5——
主证明链使用 M_{k,ε} 的**数值下界**（Theorem 6.7: M_{50,1/25} > 4.0043 等），
而 Prop 6.5 仅出现在 §6 的上界讨论（"improvement ... is asymptotically modest"）。
4.67 上界本身我们**没有证伪**（对 k=49, ε=1/25 数值上 M ≈ 3.99 < 4.67），
它可能仍真，但原证明不能作为严格引用。

## 1. 记号

按论文 Theorem 3.12：对支撑在 (1+ε)R_k（R_k = {t ≥ 0 : Σt ≤ 1}）上的 F，

- I(F) = ∫_{(1+ε)R_k} F² dt；
- J_{i,1−ε}(F) = ∫_{(1−ε)R_{k−1}} (∫₀^∞ F dt_i)² dt_{≠i}；
- M_{k,ε} = sup_F [Σ_{i=1}^k J_{i,1−ε}(F)] / I(F)。

## 2. 论文证明（Prop 6.5）与缺口位置

对 t_{≠i} ∈ (1−ε)R_{k−1}（记 s := 1−Σ_{j≠i}t_j ≥ ε）：

∫₀^{s+ε} dt_i/(s+(k−1)t_i) ≤ (1/(k−1))·log(2k−1)

⟹（Cauchy–Schwarz，逐切片固定 t_{≠i}）

(∫₀^{s+ε} F dt_i)² ≤ (log(2k−1)/(k−1))·∫₀^{s+ε} w_i(t) F² dt_i，  w_i := 1−Σt+kt_i。

对 t_{≠i} ∈ (1−ε)R_{k−1} 积分并对 i 求和，得

Σ_i J_{i,1−ε}(F) ≤ (log(2k−1)/(k−1))·Σ_i ∫_{D_i} w_i F² dt，  D_i := {t_{≠i} ∈ (1−ε)R_{k−1}}。 (1)

**缺口**：论文随即写 "Integrating in t_{≠i} and summing in i, we obtain
the claim."——隐含需要

Σ_{i∈E(t)} w_i(t) ≤ k （对 (1+ε)R_k 上 a.e. t），  E(t) := {i : t_{≠i} ∈ (1−ε)R_{k−1}}。

全空间恒等 Σ_{i=1}^k w_i = k 只在**对所有 i**（含无效切片的负项）成立；
对**有效** i 求和没有该恒等。

## 3. 反例（正测度开集）

k=49, ε=1/25。取 t = (2ε+η 重复 13 次, 0 重复 36 次)，η ∈ (−0.003, 0)：
- u = Σt = 13(2ε+η) ∈ (1.001, 1.04) ⊂ [0, 1+ε]，t 在 (1+ε)R_k **内部**；
- 有效切片恰为那 13 个（t_i = 2ε+η ≥ u−(1−ε)）；
- Σ_{i∈E} w_i = 13·[1−u+k(2ε+η)] = 13·(3.88+36η) ∈ (49.5, 50.4) **> k = 49**。

η 连续变化 ⟹ 违反发生在**正测度开集**（ess sup 意义下同样违反）。
随机采样（5 万点）中 38.7% 的点满足 Σ_{有效}w_i > k。

数值核对（论文 CS 上界在被违反点的值）：log(97)/48 × 50.4 ≈ **4.80 > 4.67**
（声称界）。

## 4. Remark 6.6（a 参数化）的严格界限

w_i^a := 1+a(−Σt+kt_i)。对有效集 E（|E| = m）：

Σ_{i∈E} w_i^a ≤ m(1−au) + aku = m + au(k−m)   （u = Σt ≤ 1+ε）。

- **a ≤ 1/(1+ε)**：au ≤ 1 ⟹ Σ_E w_i^a ≤ m + (k−m) = k —— **严格**；
- **a > 1/(1+ε)**：取 t = (1+ε, 0, …, 0)（m=1, u=1+ε）得
  Σ_E w_i^a = 1+a(1+ε)(k−1) > k —— **缺口**。

**推论**：论文声称的 a 范围 (1/(1+ε), 1/(1−ε)) 内证明不严格；
a = 1（Prop 6.5）在内，故 Prop 6.5 的证明不严格。
严格端点 a → 1/(1+ε)⁻ 给出 M_{k,ε} ≤ (1+ε)·k/(k−1)·log k
（k=49, ε=1/25: **4.1318…**）。

## 5. 影响评估（实事求是）

| 项 | 状态 |
|---|---|
| Prop 6.5 的证明 | **有缺口**（4.67 常数未由此证明推出） |
| Prop 6.5 的结论（4.67 上界） | **未证伪**（无数值反例；k=49,ε=1/25 时 M≈3.99 远低于 4.67） |
| Remark 6.6 (a>1/(1+ε)) 的证明 | **有缺口** |
| Remark 6.6 (a≤1/(1+ε)) 的证明 | **严格**（含端点 4.1318） |
| 论文主定理（H₁≤246 等） | **不受影响**（依赖数值下界 mke-lower，非 Mkeps） |
