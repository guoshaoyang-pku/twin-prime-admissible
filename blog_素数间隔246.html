1背景：孪生素数猜想与 246

孪生素数猜想（相差 2 的素数对无穷多）至今未证。目前最强无条件结果是 Maynard–Polymath8b 定理：在 Bombieri–Vinogradov 假设（BV，无条件成立）下， 存在无穷多素数间隔 ≤ 246。证明链条分三块：

  1. 筛法分析（M 侧）：Maynard 泛函 M50,ε > 4（Polymath8b 数值验证）；
  2. 可容许元组上界（SAT 侧）：存在直径 246 的可容许 50 元组（见证）；
  3. 可容许元组下界（UNSAT 侧）：不存在直径 < 246 的可容许 k 元组（H(k) 精确值）。

第 3 块（H(50) = 246 的精确性）是纯组合学问题，也是本次工作的核心。 一个可容许 k 元组 H = {h₁ < … < h_k} 满足：对每个素数 p ≤ k，H 模 p 的剩余类不覆盖全部 p 个类。

2大规模并行 UNSAT 穷举（42.4 万子空间）

判定等价（完备性可证）：∃ 直径 ≤ d 的可容许 k 元组 ⟺ ∃ 素数剩余类分配 (cp)p≤k，使 [0,d] 中避开全部 cp 的幸存位置数 ≥ k。

4Lean 4 证书验证器：把 UNSAT 侧变成机器检查证明

大规模穷举本身不是"形式化证明"。为了让 H(k) 下界达到 Lean 内核检查级别，设计了 证书验证路线（比把剪枝 DFS 搬进 Lean 省一个数量级的工作量）：

  1. 证书生成（算法 C DFS）：每个 (k,d) 输出一棵"剩余类分配失败树"—— 叶子 = 部分分配下幸存位置 < k（可直接计算验证），分支 = 素数 p 的类枚举。 全部 319 个证书仅 100,316 节点 / 218 KB（k=50 d=244 最大：12,528 节点），生成 5 秒；
  2. Lean 验证器 certValid（CertVerify.lean）：对证书树结构递归验证，终止性自动；
  3. 可靠性证明 certValidRoot_sound（Sound.lean，约 700 行，Init-only 环境手写，0 个 sorry）：
    • 幸存计数单调性（加禁类只减幸存）⟹ 叶子剪枝安全；
    • 判定等价：无含 0 可容许元组 ⟸ 所有非零分配幸存 < k（剩余类覆盖论证）；
    • 平移不变性：直径 ≤ d 可容许元组 ⟹ 含 0 且 ⊆ [0,d]（模算术 + foldl min/max）；
    • 证书归纳：验证通过 ⟹ 每个完整分配幸存 < k；
  4. 319 个定理（lean_theorems/）：
theorem H50_gt_244 : ¬ ∃ t : List Nat, admissible 50 t = true ∧ diameter t ≤ 244 := by
  exact certValidRoot_sound (k := 50) (d := 244) (c := cert_50_244) (by native_decide)

每条定理由 Lean 内核执行验证器复算证书——全部 319 条编译 EXIT 0，0 FAIL， 与 319 个 C 穷举目标一一对拍一致。H(50)=246 的下界现在是内核检查过的机器证明。
