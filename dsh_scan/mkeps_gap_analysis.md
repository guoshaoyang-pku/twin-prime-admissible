# 论文 Polymath8b Prop 6.5 (Mkeps) 证明缺陷分析——严格修复版 CS 上界

日期：2026-08-28。背景：k=49, ε=1/25 无限维严格上界攻坚中发现。

## 1. 论文的 Mkeps 命题与证明

**命题**（arXiv:1407.4897, Prop 6.5）：对 k ≥ 2, 0 ≤ ε < 1，
M_{k,ε} ≤ (k/(k−1))·log(2k−1)。

证明要点：对 F 支撑 (1+ε)R_k，t_{−i} ∈ (1−ε)R_{k−1}（s := 1−Σ_{j≠i}t_j ≥ ε）：
∫₀^{s+ε} dt_i/(s+(k−1)t_i) = (1/(k−1))·log((ks+(k−1)ε)/s) ≤ (1/(k−1))·log(2k−1)。
CS ⟹ (∫F dt_i)² ≤ (log(2k−1)/(k−1))·∫(1−Σt+kt_i)F² dt_i。
积分求和 ⟹ M_{k,ε} ≤ (k/(k−1))·log(2k−1)。∎

## 2. 缺陷：求和步骤的隐藏假设

最后一步"Integrating in t_{−i} and summing in i"需要：
Σ_i ∫_{D_i} w_i(t) F(t)² dt ≤ k·I(F)，其中 w_i = 1−Σt+kt_i = s_i+(k−1)t_i，
D_i = {t: t_{−i} ∈ (1−ε)R_{k−1}}。

**问题**：Σ_i w_i(t) = k 对所有 t 恒等（正负项抵消），但求和只对
**有效切片** i（t_{−i} ∈ (1−ε)R_{k−1}）取。对无效切片，w_i(t) 可以为负
（G_i 将非正，违反 Lemma cs 的 G_i > 0 假设），且这些负项被排除在求和外。

**反例（k=49, ε=1/25, t = (1+ε, 0, ..., 0)）**：
- u = Σt = 1.04，仅 i=1 有效（s₁ = 1 ≥ ε；其余 s_i = −ε < ε）；
- Σ_{有效} w_i(t) = w₁ = 1−(1+ε)+k(1+ε) = k(1+ε)−ε = 50.92（核验修正：此前误记为 (k−1)(1+ε)=49.92，差值恰为 +1）；
- **50.92 > k = 49**——证明需要的 Σ_{有效}w_i ≤ k 不成立；
- 缺陷条件：ε > 1/(k−1)（对 k=49：ε > 1/48；ε=1/25 与 ε=1/50 均满足）。
- 该点的 CS 上界值 = ln(2k−1)/(k−1)·50.92 = 4.853 > 4.67（Mkeps 声称值）。

**严格分析（Remark 6.6 的 a 参数化）**：w_i^a = 1+a(−Σt+kt_i)。
对有效集 E：Σ_{E}w_i^a = m(1−au)+ak·Σ_E t_i ≤ m + au(k−m)（Σ_E t_i ≤ u）。
**Σ_{E}w_i^a ≤ k ⟺ au ≤ 1**。对 u ≤ 1+ε：
- a ≤ 1/(1+ε)：au ≤ 1 ✓ **严格**；
- a > 1/(1+ε)：反例点 (t=(1+ε,0,..), m=1, u=1+ε) 给出
  Σ_{E}w_i^a = 1+a(1+ε)(k−1) > k ✗ **缺陷**。

**结论**：Remark 6.6 的 a 参数化在 a ≤ 1/(1+ε) 时严格，在 a > 1/(1+ε) 时
（含 a=1 的 Mkeps 4.67）证明有缺陷。**最优严格 CS 上界（该形状族）=
a → 1/(1+ε) 端点 = (1+ε)·k/(k−1)·log k**（k=49, ε=1/25：4.1318）——
**正是本项目定理 A 的 (★)**。即：定理 A 已是该 CS 形状族的最优严格上界。

## 3. 修复版 CS 上界（Lemma cs 严格应用）

对 t_{−i} ∉ (1−ε)R_{k−1}，J_{i,1−ε} 无贡献 ⟹ G_i 在这些切片无约束（可取 ∞）。
严格上界：

M_{k,ε} ≤ ess sup_{t ∈ (1+ε)R_k} Σ_{i: t_{−i} ∈ (1−ε)R_{k−1}} 1/G_i(t)，
约束（仅有效切片）：∫₀^{s_i+ε} G_i(t_i; t_{−i}) dt_i ≤ 1。

**逐切片归一化（合法构造）**：G_i(t) = c(s_i)·(s_i+(k−1)t_i)^{-1}，
c(s) = (k−1)/log((ks+(k−1)ε)/s)（精确 ∫G_i = 1）。
数值 sup（k=49, ε=1/25，对称 t 网格 + 局部优化）：
- β=1（论文形逐切片归一化）：**4.807**（点 13×(2ε), 0×36）；
- β=1.2（G ∝ 1/(βs+48x)）：**4.627**（最优 β ≈ 1.2）；
- β 族最小 ≈ 4.627，仍 > 4。

**幂族 G ∝ (s+48x)^{-p}**：p=1 最优（4.807），p ≠ 1 更差。
**指数族 G ∝ e^{−γx/L}**：最优 γ≈3 给 16.1——远差于线性。
**正系数对称多项式 F**（F = Σc_j(1+ε−P₁)^r p_γ, c_j ≥ 0 ⟹ F ≥ 0，
G_i = F/∫F dt_i）：D=15 基初始 sup=24.7（c=1），优化未见 < 4。
**张量 minimax**（逐切片独立形状，SLSQP/L-BFGS-B 活跃集）：
最优 ≈ 4.00-4.05（数值，惩罚法下界收敛）——**未突破 4**。

## 4. 结论与意义

1. **论文 Mkeps (a=1, 4.67) 与 Remark 6.6 (a > 1/(1+ε)) 的证明缺陷**——
   对 ε > 1/(k−1) 是新的文献观察（反例点 t = (1+ε, 0, ..., 0)）。
   数值上这些上界仍真（M ≈ 3.99 < 4.67/4.13），但**证明链断裂**，
   不能作为严格引用。
2. **最优严格 CS 上界（论文形状族）= 定理 A 的 (★) = (1+ε)k/(k−1)·log k**
   （k=49, ε=1/25：4.1318）——我们的定理 A 已达该族最优。
3. **修复版 CS（逐切片独立 G）数值 minimax ≈ 4.0-4.1**（β 族 4.627、
   张量活跃集 4.00-4.05）——与"CS 下界定理"猜想一致：CS 上界原理上
   无法证明 M_{49,1/25} < 4（下限 ≈ 4.13）。
4. 无限维严格上界的唯一出路：**谱方法 Galerkin 误差界**
   ||R_{k,ε} − P_N R_{k,ε} P_N|| 的显式估计（需 ||(I−P_N)R|| < 2.1e-4，
   缺口 = 4/k − λ_31 = 4/49 − 0.0814226 = 2.1e-4；数值误差 ≈ 1e-5，
   有 20 倍裕量）——论文级工程。
