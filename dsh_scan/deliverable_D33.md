## (a) 被 LDL 分解的矩阵（精确陈述）

**记号**（论文 arXiv:1407.4897 一致）：
- R_k = {t ∈ [0,∞)^k : Σt ≤ 1}，放大单纯形 (1+ε)R_k；
- 基（论文等价）：e_a(t) = (1+ε−P₁(t))^{r_a}·p_{γ_a}(t)，其中 P₁ = Σt，
  p_γ = Π_{d∈γ}(Σ_j t_j^d)，γ 为偶划分，r_a + deg(γ_a) ≤ 33；
- V₃₃ = span{e_a : a = 1..6740}（对称多项式子空间，D=33，n=6740）。

**二次型**：
- 分母 B（= I 矩阵）：B_{ab} = ∫_{(1+ε)R_k} e_a(t) e_b(t) dt = ⟨e_a, e_b⟩_{L²((1+ε)R_k)}；
- 分子 A（= J1 矩阵）：A_{ab} = Σ_{i=1}^{k} ∫_{(1−ε)R_{k−1}} (∫_0^{1+ε−Σ_{j≠i}t_j} e_a dt_i)(∫_0^{1+ε−Σ_{j≠i}t_j} e_b dt_i) dt_{≠i}，
  即 Maynard ε-trick 二次型 Σ_i J_{i,1−ε}(e_a, e_b)；
- 二者均为精确有理数矩阵（Fraction，由 frac_multi.py 构建，
  frac_cache_49_33_e1_25.pkl 存储）。

**判定矩阵**：
C := (4/k)·B − A = (4/49)·B − A ∈ ℚ^{6740×6740}。
- C 正定 ⟺ 对所有 v ≠ 0：vᵀAv / vᵀBv < 4/k ⟺ k·(vᵀAv/vᵀBv) < 4 ⟺
  M_{49,1/25}(V₃₃) := sup_{v≠0} k·vᵀAv/vᵀBv < 4。
- 等价形式：4B − kA 正定（差常数因子 k）。

**LDL^T 分解的对象**：对角平衡后的 C' = D·C·D（D_ii = 1/√C_ii，正对角合同
变换保持正定性），在 flint.ctx.prec = 2000 bits 区间算术下做对称选主元
LDL^T（iv_strict_arb2.py）。全部 6740 个主元的区间下界 > 0 ⟹ C 正定。
