# M 侧攻坚终报——超越 246 的数值尝试（精确算术）

> 目标：检验是否存在 k < 50 与 ε ∈ (0,1) 使 M_{k,ε} > 4，从而经
> Polymath8b 的 ε-trick 定理（EH[1/2]=Bombieri–Vinogradov 下无条件）得到
> DHL[k,2] 与 H ≤ H(k) < 246。
> 全部矩阵为精确有理数（gmpy2.mpq）；全部结论由**精确 Rayleigh 验证**
> （k·aᵀJ₁a − 4·aᵀIa > 0 的精确有理数不等式）或完全收敛的 640 位幂迭代给出。

## 3. 路线 B：min 截断分段族（(1+ε−P₁)^a·(1−ε−M₁)₊·p_γ）

- 动机：论文 8.5 节脚注——最优 F 应在中心区域 {Σ_{i≠i₀}t_i ≥ 1−ε ∀i₀} 上消失；
  (1−ε−M₁)₊ 因子（M₁ = max_i P₁^{(i)}）精确捕捉该结构。
- 全部分析闭式：I 侧 K/K2q（min_core.py），J1 侧 JT + 边际三段展开（routeB_build.py/routeB2.py），
  逐项验证：k=2 手算一致（0.0959228586667）；k=13 全矩阵 MC 比值 1.00–1.11。
- 增益探针（k=13, DP=DM=4）：P-only M=2.8034 → P+M M=2.8260（**+0.0226, +0.8%**）。
- k=49 DP=25 DM=7/13 的精确矩阵构建中（DM=13: 1930 基, 6.32M jtval 键）。
- 若 DM=7 增益 ≥ +0.013 → 4.0 越线 → 严格证书 + DHL[49,2] + 宽度 240 元组（已验证可容许）
  ⇒ **素数间隙 ≤ 240 < 246**。若增益不足 → 诚实报告：246 是该框架内可达的边界。

## 4. 最终结论（当前状态）

1. 论文全部关键数值被精确复现（§1）——计算管线端到端可信。
2. 多项式族对 k<50 无法越过 4（§2）——k=49 最优 ε 下 3.987, 距 4 差 0.013；
   k=49→50 的族值跳跃恰跨过 4（3.9871 → 4.0043），246 即该族的边界。
3. 路线 B 分段族是最后的越线机会（§3），结果待出。
