> 目标：检验是否存在 k < 50 与 ε ∈ (0,1) 使 M_{k,ε} > 4，从而经
> Polymath8b 的 ε-trick 定理（EH[1/2]=Bombieri–Vinogradov 下无条件）得到
> DHL[k,2] 与 H ≤ H(k) < 246。
> 全部矩阵为精确有理数（gmpy2.mpq）；全部结论由**精确 Rayleigh 验证**
> （k·aᵀJ₁a − 4·aᵀIa > 0 的精确有理数不等式）或完全收敛的 640 位幂迭代给出。

## 3. 路线 B：min 截断分段族（(1+ε−P₁)^a·(1−ε−M₁)₊·p_γ）

- 动机：论文 8.5 节脚注——最优 F 应在中心区域 {Σ_{i≠i₀}t_i ≥ 1−ε ∀i₀} 上消失；
  (1−ε−M₁)₊ 因子（M₁ = max_i P₁^{(i)}）精确捕捉该结构。
- 全部分析闭式：I 侧 K/K2q（min_core.py），J1 侧 JT + 边际三段展开（routeB_build.py/routeB2.py），
  逐项验证：k=2 手算一致（0.0959228586667）；k=13 全矩阵 MC 比值 1.00–1.11。
- 增益探针（k=13, DP=DM=4）：P-only M=2.8034 → P+M M=2.8260（**+0.0226, +0.8%**）。
- **k=49 最终结果（DP=25, DM=7, ε=1/25, n=1808）**：
  - 精确矩阵构建完成（frac_cacheB_49_25_7_e1_25.pkl，632,380 个 jtval 键，
    JT0 表 4,541,040 项），640 位 mpfr 幂迭代 500 步完全收敛。
  - **M = 3.9843383258**；精确 Rayleigh 检验 k·num−4·den = −2.1e-33 < 0。
  - 对照：同 ε 同 D 的多项式族 M = 3.9843342389 —— **min 截断增益仅 +4e-6**，
    远低于越线所需 +0.013。DM=13（1930 基, 6.32M 键）外推增益 ≤ 1e-5，不改变结论。
  - 关键观察：min 截断对 k=13 有 +0.8% 增益，但对 k=49 几乎为零——
    大 k 时 P₁ 的分布集中在中心区域边缘，截断因子恒为 1 或趋于常数，
    论文脚注的"最优 F 在中心区域消失"在 k=49 已由多项式族自身近似实现。

## 4. 最终结论（终报）

1. 论文全部关键数值被精确复现（§1）——计算管线端到端可信。
2. 多项式族对 k<50 无法越过 4（§2）——k=49 最优 ε 下 3.987, 距 4 差 0.013；
   k=49→50 的族值跳跃恰跨过 4（3.9871 → 4.0043）。
3. 路线 B（最后一项理论杠杆）已彻底计算：k=49 上 min 截断增益 +4e-6，
   M = 3.9843383 与多项式族几乎重合（§3）。**k<50 不存在（可计算子空间内的）
   M_{k,ε} > 4 的数值证据。**
4. **诚实结论**：在本框架（Maynard–Polymath8b 筛法 + ε-trick + 已知可容许元组）内，
   **246 是该框架可达的严格边界**——k=50 是越过 4 的最小 k，其最优可容许
   元组宽度恰为 246。k<50 的全部数值搜索（多项式族各 ε/D + min 截断分段族）
   一致收敛于 M ≤ 3.987 < 4，距 4 有 0.013 的实质缺口。
   注意：这**不是**"M_{k<50} < 4 已被证明"——那是开放问题；这是
   "在已实现的最大子空间族中，数值上不存在越线者"，且论文原作者的
   k=49 尝试同样未成功（newergap-submitted.tex 2841 行：k=49 开放）。
   超越 246 需要新的数学思想（而非更大计算），例如：
   - 改进 EH 假设（广义 Elliott–Halberstam 已给 6，非无条件）；
   - 新的可容许元组构造（Dickson 猜想下更窄，非无条件）；
   - 全新的筛法泛函分析框架。
5. 已证结果与文献边界请严格区分（见 repo 顶层 README / analytic_bound_proof.md）：
   - 已证（本工作 + 论文）：M_{50,1/25} > 4 ⇒ 素数间隙 ≤ 246（无条件）；
   - 复现/验证：本工作精确复现论文全部关键数值；
   - 开放：k<50 的 M_{k,ε} 是否 < 4（未证，本工作数值强烈支持 < 4）。
