# 分段多项式基攻击 M_{k,ε}（路线 B）——设计文档

> 目标：若多项式基（论文族）的 k=49 ε-调优值止步于 ~3.99 < 4，
> 用**捕获最优 F 结构**的分段多项式基再攻 M_{k,ε} > 4。
> 依据：论文 newergap-submitted.tex §8.5 脚注（第 2842 行附近）：
> "the optimal choice F for M_{k,ε} should vanish on the polytope
>  { t ∈ (1+ε)·R_k : Σ_{i≠i₀} t_i ≥ 1-ε for all i₀ = 1..k }"
> 即最优 F 在"中心区域"（所有 k-1 元边余量都超过 1-ε 处）取 0，
> 这正是多项式基最难表达、而分段多项式天然具备的结构。

## 1. 变分问题（Bombieri–Vinogradov 可用的 ε-trick，Theorem "epsilon-trick"(i)）

- F: [0,∞)^k → R, 平方可积, supp F ⊆ (1+ε)R_k = {Σt_i ≤ 1+ε}, ε ∈ (0,1) 自由。
- I(F) = ∫_{(1+ε)R_k} F²,  J_{i,1-ε}(F) = ∫_{(1-ε)R_{k-1}} (∫_0^∞ F dt_i)² dt_{-i}。
- 判据：M_{k,ε} := sup Σ_i J_i / I > 4  ⇒  DHL[k,2]（EH[1/2]=BV 下无条件）。
- k=49 ⇒ H ≤ 240（witness 元组已验证）；k=48 ⇒ 236；k=47 ⇒ 226；k=46 ⇒ 216。
- 对称最优性：I(F̃) ≤ I(F), ΣJ_i(F̃) = ΣJ_i(F)（F̃ = 置换平均，Cauchy–Schwarz）
  ⇒ 最优 F 可取对称。基准由论文多项式的等价基复现：k=50, ε=1/25, d=27 → 4.0043。

## 2. 结构基设计

记 P₁ = Σ_i t_i,  h_i = 1-ε-P₁+t_i （= 1-ε-Σ_{j≠i}t_j）。
中心区域 C = {t : h_i < 0 ∀i}。

### 2.1 全对称乘积因子（s=1 满血版）
  b_{a,γ}(t) = (1+ε-P₁)^a · Π_{i=1}^k (h_i)_+ · p_γ(t),   a + k + deg(γ) ≤ D
- Π_i(h_i)_+ 恰在 C 上为 0 ✓（结构精确匹配脚注）；
- 但度为 k：k=49 时 s=1 吃掉全部预算，a=deg=0 只剩 1 个基函数 → 太贫。
- 改进：允许 (h_i)_+ 的**对称初等组合** e_s(h) = Σ_{|S|=s} Π_{i∈S} h_i（度 s）：
  b_{a,s,γ} = (1+ε-P₁)^a · e_s(h) · p_γ,  a + s + deg(γ) ≤ D
  每个乘积项 Π_{i∈S} h_i 在 {h_i<0 ∀i∈S} 上为 0（部分消失结构）；
  S 越大越接近 C-消失，但支撑锥越多，积分越碎。

### 2.2 带 _+ 的截断乘积（真分段）
  b_{a,S,γ}(t) = (1+ε-P₁)^a · Π_{i∈S}(h_i)_+ · p_γ,  |S| = s ≤ 2..3
- 支撑 = (1+ε)R_k ∩ {h_i>0, i∈S} = 多面体 {Σt ≤ 1+ε, Σt-t_i < 1-ε (i∈S)}。
- |S|≤2 的积分闭式可行（单变量截断的 Dirichlet 型积分）；
- |S|≥3 需要多面体三角剖分（组合爆炸）——先做 |S|≤2。

## 3. 精确积分公式（矩阵元素）

只需两类主积分（p_γ 展开为单项式对称函数后）：
  (A) ∫_{(1+ε)R_k} (1+ε-P₁)^M · Π_{i=1}^k t_i^{j_i} dt
      = (1+ε)^{k+M+Σj} · M! · Π_i j_i! / (k+M+Σj)!          （Lemma bfi 直推）
  (B) 截断型 ∫_{R ∩ {P₁-t₁ < c}} (1+ε-P₁)^M · t₁^{j₁} · Π_{i≥2} t_i^{j_i} dt
      = 在 t₁ ∈ [max(0, P₁'-c), 1+ε-P₁'] 区间积分（P₁' = Σ_{i≥2}t_i），
      外层对 t' ∈ (1-ε)R_{k-1} 仍是 Dirichlet 型，可表为 (A) 类积分的线性组合
      （区间端点 P₁'-c 引入 (1-ε) 边界分裂，产生 ~2 个半空间积分的差）。

关键：所有积分仍落在 "H 槽位 DP + 阶乘" 框架内，只需扩展 split_a 支持
"t₁ 的截断区间"（新增 split 维度：t₁ 分给区间 [0, P₁'-c] 或 [P₁'-c, ...]）。
J1（边余量）同理：∫(∫_0^∞ F dt₁)² over (1-ε)R_{k-1} 在 t' 上分段。
矩阵元素全部精确有理数（Fraction/mpq），后续流程（rayleigh_check/parallel_ldl）复用。

## 4. 计算预算估计

- 基大小：s ≤ 2, γ 偶数, a+s+deg ≤ D：约 (D/2)·(偶数划分数) 的 3 倍 → D=25 约 n ≈ 5000-8000。
- 矩阵构建：frac_multi 并行框架复用（截断 split 使每对项数 ×3-6）→ 预估 10-30 min。
- 特征/验证：rayleigh_check（缩放 + 精确 LU + 幂迭代 + 精确 Rayleigh）——n=5000 的 LU
  约 n³/3 ≈ 4e10 mpq 运算 ≈ 数小时（单核）；可行但慢，必要时块并行。
- 先在小 k（k=4,6 与论文 4d 节对照验证公式）做正确性检验。

## 5. 期望收益与决策点

- 多项式族 k=49 ε=1/25 的 D=25/27 精确值出来后：
  * 若 ≥ 4.00 → 直接严格化，路线 B 不需要；
  * 若 3.97-3.99 → 路线 B 只需 +0.01-0.03 的增益（结构增益预估 0.01-0.05，有希望）；
  * 若 < 3.97 → 路线 B 希望渺茫，转为诚实报告。
- 路线 B 的每个 (k,ε) 胜出同样走：精确矩阵 → 精确 Rayleigh > 4 → 严格定理。
