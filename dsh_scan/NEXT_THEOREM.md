## 2. 形式化关系（被分解矩阵的精确含义）

- 基（论文等价）: e_a(t) = (1+ε−P₁)^{r_a}·p_{γ_a}(t)，r_a+deg(γ_a) ≤ 33，
  γ_a 偶划分；V₃₃ = span{e_a : a=1..6740}（对称多项式子空间）。
- B := Gram 矩阵，B_{ab} = ∫_{(1+ε)R_k} e_a e_b dt；
- J1 := Maynard 分子（**单切片 i=1 约定**，由 kk=2 精确验证确认：
  J1_{ab} = ∫_{t_{≠1}∈(1−ε)R_{k−1}} (∫₀^{1+ε−Σ_{j≠1}t_j} e_a dt₁)(∫₀^{…} e_b dt₁) dt_{≠1}；
  M = k·λ_max(J1, B)）；
- 被分解矩阵 C := (4/k)·B − J1 ∈ ℚ^{6740×6740}；
- **等价性**（G3 kk=2 确定性验证通过，rel = 0）：
  C 正定 ⟺ 对所有 v≠0: vᵀJ1v/vᵀBv < 4/k ⟺ k·vᵀJ1v/vᵀBv < 4
  ⟺ **M_{49,1/25}(V₃₃) < 4**（V₃₃ 上 Rayleigh 商严格小于 4）。
  因此 A 级事实的精确表述：**在 6740 维 V₃₃ 上，M_{49,1/25}(V₃₃) < 4
  有区间算术严格证书**。

## 3. 为什么这不能推出全空间上界（诚实边界）

V₃₃ ⊂ V_full（V_full = 对称 L²((1+ε)R_k)，或全 L²）。对任意子空间 V ⊂ V_full：

sup_{F∈V} k·Σ_i J_{i,1−ε}(F)/I(F) ≤ sup_{F∈V_full} k·Σ_i J_{i,1−ε}(F)/I(F) =: M_{49,1/25}。

即 M(V₃₃) 是 M_full 的**下界信息**（M_full ≥ 3.9902624483，来自高精度
Rayleigh 证书），有限维证书**不能推出** M_full < 4。多维奇偶基外推
（6 严格点，外推 ≈ 3.9906）只是 B 级数值趋势。

## 4. 下一定理（精确目标，二选一）

### 目标 A（首选）：显式 Galerkin 尾项/补空间界

**定理（待证）**: 存在可计算的常数序列 c(D) → 0（D → ∞），使

M_{49,1/25} ≤ M(V_D) + c(D),  对每个 D = 33, 35, 37, …

其中 c(33) < 4 − 3.9902624483 ≈ 0.00973755 即可给出
M_{49,1/25} < 4 的全空间上界。

**需要的中间量（可复验）**:
1. 补空间投影算子 P_D^⊥ := I − P_{V_D}（V_D ⊂ V_full 关于 I(·)=⟨·,·⟩_{L²((1+ε)R_k)}
   的正交投影）；
2. 尾项算子范数界: c(D) ≥ || (I − P_D^⊥)?? || —— 具体形式建议:
   c(D) := k·||J1^{1/2} (I − P_{V_D}) J1^{1/2}||_{op}（或等价 Galerkin 误差界
   ||J1 − P_{V_D} J1 P_{V_D}||_{op} 的显式上界），其中 J1 视为 V_full 上的
   单切片积分算子（核显式: 1_{t_{≠1}∈(1−ε)R_{k−1}}·L(t_{≠1}) 型）；
3. 核的正则性: 证明 J1 的核属于某加权 Sobolev 类 W^{s}（s 显式），并给出
   对称多项式基的显式 Jackson 型逼近常数（含 D, k, ε 的显式依赖）；
4. 可复验数值中间量: c(31), c(33) 的高精度估计（用 V_35 或 V_37 的 Rayleigh
   差 λ(V_37)−λ(V_33) 作为 c 的下界检验，不得冒充上界）。

**失败判据**: 若对 D=33 需要 c(33) < 0.0097 而任何合法证明给出
c(33) ≥ 0.0098（或证明无法闭合常数），目标 A 判定失败并如实报告。

### 目标 B：直接全空间上界引理（非外推）

**定理（待证）**: 存在显式、严格正、可逐点验证的权 w 或逐 i 权族 {w_i}，
使乘子不等式（引理已证，见 multiplier_route/multiplier_lemma.md）成立:

sup_{t∈(1+ε)R_k} [Σ_{i: t_{≠i}∈(1−ε)R_{k−1}} W_i(t_{≠i})] / w(t) < 4,

W_i(t_{≠i}) := ∫₀^{1+ε−Σ_{j≠i}t_j} w dt_i（或逐 i 对偶形式）。

**需要的常数**: w 的显式系数（有理或闭式）、sup 的严格区间上界 < 4
（用区间算术对 (1+ε)R_k 的剖分验证）、w > 0 的显式下界。

**失败判据**: 若所有已测权类（Ritz/多项式/分段/类 LP）的 sup 下确界
≥ 4.13（已有多方 B 级证据: per-i 族地板 ≈ 4.13，C 级报告），且无法构造
新权类使其 < 4，目标 B 判定失败——此时乘子路线**原则性不可行**的猜想
（CS 下界定理方向）应作为单独开放问题陈述。
